## Prerequisites

- Docker (running)
- [`uv`](https://docs.astral.sh/uv/getting-started/installation/)
- An LLM API key from any [supported provider](/llm-providers/overview) (OpenAI, Anthropic, Google, etc.)

## Installation

This fork is run from source.

```bash
# Clone and install
git clone https://github.com/pt-act/oriontrix.git
cd oriontrix
uv sync

# Build the sandbox image (Kali + pinned security tools)
./scripts/docker.sh dev
export ORIONTRIX_IMAGE="oriontrix-sandbox:dev"
```

## Configuration

Set your LLM provider:

```bash
export ORIONTRIX_LLM="openai/gpt-5.4"
export LLM_API_KEY="your-api-key"
```

<Tip>
For best results, use `openai/gpt-5.4`, `anthropic/claude-opus-4-6`, or `openai/gpt-5.2`.
</Tip>

## Run Your First Scan

```bash
uv run oriontrix --target ./your-app
```

<Note>
Results are saved to `oriontrix_runs/<run-name>`. Ensure `ORIONTRIX_IMAGE` points at the sandbox image
you built (`oriontrix-sandbox:dev` above).
</Note>

## Target Types

Oriontrix accepts multiple target types:

```bash
# Local codebase
oriontrix --target ./app-directory

# GitHub repository
oriontrix --target https://github.com/org/repo

# Live web application
oriontrix --target https://your-app.com

# Multiple targets (white-box testing)
oriontrix -t https://github.com/org/repo -t https://your-app.com
```
